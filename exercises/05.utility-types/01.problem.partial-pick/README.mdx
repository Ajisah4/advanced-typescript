# Partial and Pick

<EpicVideo url="https://www.epicweb.dev/workshops/advanced-typescript/utility-types/partial-pick" />

👨‍💼 We need to create types for updating user data. Some fields should be
optional, and we only want to allow updating specific fields.

```ts
type Article = {
	id: string
	title: string
	body: string
	updatedAt: Date
}

type ArticlePatch = Partial<Pick<Article, 'title' | 'body'>>
```

🐨 Open <InlineFile file="index.ts" /> and:

1. Create `PartialUser` — all `User` properties optional
2. Create `UserNameEmail` — only `name` and `email`
3. Create `UserUpdate` — optional updates limited to `name` and/or `email`
4. Remove the `@ts-expect-error` once `UserUpdate` exists
5. Export `updateUser`

Observable behavior for the provided `user` fixture:

- `updateUser(user, { name: 'Alice Smith' })` → name becomes `'Alice Smith'`,
  email stays `'alice@example.com'`, id stays `'1'`
- `updateUser(user, { email: 'alice.smith@example.com' })` → email updates,
  name stays `'Alice'`
- Updating both fields at once also works
- Updating `id` should be a type error
