# Index Access Types

<EpicVideo url="https://www.epicweb.dev/workshops/advanced-typescript/4-type-operators/index-access" />

👨‍💼 Index access types let you extract property types from other types using
bracket notation.

```ts
type Recipe = {
	title: string
	author: { name: string; rating: 1 | 2 | 3 | 4 | 5 }
}

type TitleType = Recipe['title'] // string
type AuthorType = Recipe['author'] // { name: string; rating: 1 | 2 | 3 | 4 | 5 }
type RatingType = Recipe['author']['rating'] // 1 | 2 | 3 | 4 | 5
```
