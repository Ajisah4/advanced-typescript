# Basic Conditionals

<EpicVideo url="https://www.epicweb.dev/workshops/advanced-typescript/6-conditional-types/basic-conditionals" />

👨‍💼 Let's create conditional types that check and transform based on type
conditions.

```ts
type IsNumber<T> = T extends number ? true : false
type UnwrapArray<T> = T extends Array<infer U> ? U : T

type A = IsNumber<42> // true
type B = UnwrapArray<Array<'x'>> // 'x'
```

🐨 Open <InlineFile file="index.ts" /> and:

1. Create these conditional types:
   - `IsString<T>` → `true` / `false`
   - `IsArray<T>` → `true` / `false`
   - `IsFunction<T>` → `true` / `false`
   - `Flatten<T>` → element type when `T` is an array, otherwise `T`
   - `MyNonNullable<T>` → removes `null` and `undefined`
2. Implement a runtime helper `process(value)` that:
   - Returns the first element when `value` is an array
   - Returns `value` unchanged otherwise
   - Uses `Flatten` for its return type
3. Export `process`

Completion checks:

- `process([1, 2, 3])` → `1`
- `process(42)` → `42`
- `process(['a', 'b', 'c'])` → `'a'`
- `process(100)` → `100`
