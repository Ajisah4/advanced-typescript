# Creating Promises

<EpicVideo url="https://www.epicweb.dev/workshops/advanced-typescript/1-promises/creation" />

👨‍💼 We need to simulate an API call that fetches user data. Let's create a
Promise that resolves with user information after a delay.

```ts
type Forecast = { day: string; high: number }

const fetchForecast = () =>
	new Promise<Forecast>((resolve) => {
		setTimeout(() => resolve({ day: 'Mon', high: 72 }), 500)
	})
```

🐨 Open <InlineFile file="index.ts" /> and:

1. Create and export a `fetchUser` function that returns a `Promise<User>`
2. Resolve after a short delay (about 1 second is fine; a few milliseconds is
   fine for faster checks)
3. Resolve with this user fixture:
   - `id: '1'`
   - `name: 'Alice'`
   - `email: 'alice@example.com'`

Completion check: calling `await fetchUser()` returns that exact user object.
