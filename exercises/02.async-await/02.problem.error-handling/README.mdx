# Error Handling with Async/Await

<EpicVideo url="https://www.epicweb.dev/workshops/advanced-typescript/2-async-await/error-handling" />

👨‍💼 Our async code needs proper error handling. Let's use try/catch to handle
failures gracefully.

```ts
async function readConfig() {
	if (Math.random() > 0.5) throw new Error('Missing config')
	return { theme: 'dark' }
}

async function loadSettings() {
	try {
		const config = await readConfig()
		return config
	} catch (error) {
		return { theme: 'light', error }
	} finally {
		// cleanup
	}
}
```

2. Add a `catch` that handles failures internally (do **not** rethrow)
3. Optionally add a `finally` block for cleanup logging
4. Export `loadUserData`

Behavior of the provided helpers:

- `fetchUser('1')` resolves to Alice
- `fetchUser` with any other id rejects with `Error('Failed to fetch user')`

Completion checks:

- `await loadUserData('1')` completes without throwing
- `await loadUserData('2')` also completes without throwing (error handled
  inside the function)
